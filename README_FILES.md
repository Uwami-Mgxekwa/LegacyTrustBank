# 🏦 Legacy Trust Bank - File Structure Guide

## 📁 Project Structure

### **Main Banking Application**
- **`index.html`** - Main banking app with login and dashboard
- **`website/style.css`** - Shared CSS styles for both apps
- **`website/script.js`** - Website-specific JavaScript

### **Marketing Website**
- **`website/marketing.html`** - Company marketing/info website
- **`website/style.css`** - Shared CSS styles
- **`website/script.js`** - Website navigation and animations

1. **Marketing Website:** Open `website/marketing.html` to see company info

3. **Login:** Use any username/password combination
